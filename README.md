# 🧠 JavaScript Challenges

Repositório dedicado à resolução de desafios práticos de **JavaScript**, com foco no desenvolvimento de lógica de programação, capacidade de resolução de problemas e domínio dos fundamentos da linguagem.

## 🎯 Objetivo

O objetivo deste repositório não é apenas praticar a sintaxe do JavaScript, mas **aprender a pensar como programador**.

Os desafios foram desenvolvidos para testar a capacidade de:

* Analisar problemas;
* Criar estratégias para chegar a uma solução;
* Transformar uma ideia em algoritmo;
* Utilizar funções, arrays, objetos, loops e condicionais;
* Trabalhar com strings e dados;
* Resolver problemas sem depender do DOM;
* Escrever soluções organizadas e reutilizáveis;
* Testar diferentes casos e identificar possíveis erros.
